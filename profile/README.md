Koi checks whether ChatGPT, Gemini, Google AI Mode and Google AI Overviews recommend your
product, and which competitors they recommend instead. It is an open-source alternative to
Profound and Peec AI, built for developers and their coding agents.

- **[koi](https://github.com/koihq/koi)**: the app. Go, React and PostgreSQL, MIT licensed.
- **[Koi Cloud](https://getkoi.co)**: the hosted version.

Self-host it with one command:

```sh
curl -fsSL https://raw.githubusercontent.com/koihq/koi/main/install.sh | sh
```

Connect Claude Code, Codex or Cursor over [MCP](https://github.com/koihq/koi/blob/main/docs/mcp.md)
and let your agent turn the results into changes.
